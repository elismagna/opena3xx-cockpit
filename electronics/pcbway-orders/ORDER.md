# PCBWay order pack — A320 cockpit (MobiFlight open hardware)

Source: [MobiFlight/mobiflight-panels](https://github.com/MobiFlight/mobiflight-panels) `aircraft/airbus-a32x/` (GPL-3.0).  
Generated: local EasyEDA→Gerber converter + upstream Gerber zips where available.

**Before you click Pay:** open the local color gallery (`_previews/index.html` → http://127.0.0.1:8765/), the **3D + parts** viewer (`viewer3d.html?board=21-adirs`), or the **panel sim** (`sim.html?board=21-adirs` — 3D + local Falstad/CircuitJS face I/O), or upload each `Gerber.zip` to [PCBWay Online Gerber Viewer](https://www.pcbway.com/project/OnlineGerberViewer.html). Zips use PCBWay layer names (`Gerber_TopLayer.GTL`, …, `Drill_PTH_Through.DRL`). Prefer upstream (`01`–`03`) over `15`. Rebuild part markers: `python electronics/tools/extract_board_components.py`. Rebuild circuits: `python electronics/tools/build_falstad_circuits.py`.

**Readiness:** `python electronics/tools/build_pcbway_ready.py` → `_previews/pcbway-ready.json` (29/30 ready; skip `15`). Each zip’s `How-to-order-PCB.txt` lists copper layer count and outline size. **`01-mcdu` is 4-layer** (paste + NPTH); all others are 2-layer.

**After fab (direct comparison):** MobiFlight Fenix/FBW LVar bindings are already sampled in `pcbway-ready.json` (`sim_bindings`) for packs with `.mcc` configs — that matrix is the bridge for side-by-side instrument state vs sim/real electrical data.

## Custom Rev0 boards (`16`–`30`) — from face SVG

Auto-generated by `tools/svg_face_to_pcb.py` (red cutout rects/circles → pads + edge header), routed by `tools/maze_router.py` (2-layer A*, 0.30 mm track / ≥0.20 mm clearance / 0.4–0.7 mm tented vias).  
**Check before ordering:** `python electronics/tools/check_rev0_drc.py` must print `all clean` (reads only the Gerber zip + `PINOUT.csv`: clearances, NPTH/edge keep-outs, shorts between header nets, every SW/LED/GND pin reaching its button).

Each folder has `PINOUT.csv` (header pin → net). Per button: `SWn` (switch to GND, MobiFlight input) and `LEDn` (anode; put ~330 Ω in series on the Mega side). Two GND pins on every header.

> Earlier Rev0 zips (before this fix) drew every trace on top copper without collision checks and had shorts on all 15 boards, plus no GND return. Do not order zips from commit `191397f`.

Cutout fixes landed for flood (147×48), elec (11 btn), hyd-fuel (14 btn). Rotary knob cutouts still get the pushbutton footprint in Rev0.

Deferred (not flat PCB packs): MIP gear lever, brake-pressure gauge, pedestal parking brake.

## Converter caveat

`tools/easyeda_to_gerber.py` emits tracks, vias, pads, holes, silk strokes, and outline. **Copper pours are outline-only** (not filled). That is OK for many MobiFlight panels that route discretely; still verify pours/ground planes visually before fab.
